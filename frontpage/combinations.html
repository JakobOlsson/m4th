COUNTING · COMBINATIONS

Choose a group; ignore its order.

If we select several distinct items and only care which items were chosen—not the order we picked them in—we are counting combinations. Factorials give us a compact way to count how many such groups are possible.

List a small example first.

A set is a collection of distinct items. We can write the available letters as {A,B,C}. A subset is a set made from some of those items. If we choose two letters, one subset is {A,B}. A combination is a subset of a specified size: the members are what matter, not their order.

Choose 2 from A, B, C

The possible two-item subsets are {A,B},{A,C},{B,C}. These are all the pairs; there are three. If order mattered, AB and BA would be counted separately; as sets, they are the same subset.

GroupWhy it appears once
A and BPicking A then B or B then A makes the same group.
A and CPicking A then C or C then A makes the same group.
B and CPicking B then C or C then B makes the same group.

So there are 3 combinations. Order matters for a sequence or arrangement; it does not matter for a combination.

The choose notation

We can write “choose 2 from 3” using a binomial coefficient. The top number is the number of available items; the bottom number is how many we choose. Despite the tall parentheses, this is one number—not a fraction. Here both counts are whole numbers, and the number chosen cannot exceed the number available.

NOTATION(32)=3
READ IT ALOUD

Three choose two equals three: there are three ways to choose two items from three when order does not matter.

This number is commonly called a binomial coefficient. A coefficient is a number that multiplies another quantity: in 3x, 3 is the coefficient of x. A binomial is an expression with two terms added or subtracted, such as x+y. These are called binomial coefficients because they occur as multipliers when repeated copies of a binomial are multiplied out. A binomial does not have to evaluate to a nonzero number: if x is one and y is negative one, x+y=0. A nonzero requirement applies only when an expression is used below a fraction bar, because division by zero is undefined. You do not need the binomial connection to use the counting rule here: “n choose r” means the number of ways to choose r items from n.

Why factorials count the groups

First count ordered selections of 2 from 3: there are 3 choices for the first letter and 2 remaining choices for the second, giving six ordered pairs: AB, BA, AC, CA, BC, and CB. Every unordered group is counted twice, once in each order, so divide by two. In factorial notation, the count is three factorial divided by two factorial times one factorial, which gives three.

For a general choice of r items from n distinct items, count ordered selections first: there are n choices, then n − 1 choices, continuing until r items have been chosen. Multiplying these counts gives the number of ordered selections:

ORDERED PICKSn(n−1)⋯(n−r+1)=n!(n−r)!
READ IT ALOUD

Multiply n, n minus one, and each next smaller number, stopping after r choices. This equals n factorial divided by the factorial of n minus r.

But each group of r items appears in r! different orders. Divide the ordered count by r! to count each group once:

GENERAL RULE(nr)=n!r!(n−r)!
READ IT ALOUD

n choose r equals n factorial divided by the product of r factorial and the factorial of n minus r. The division removes the extra counting caused by order.

For our example, there are three items and we choose two. Substituting those values in the formula gives three, matching our list. We can only choose from zero items up to all the items available; we cannot choose a negative number or more items than we have.

SUBSTITUTE(32)=3!2!·1!=3
READ IT ALOUD

Three choose two is three factorial over two factorial times one factorial, which equals three.

What does the result tell us?

The result of the factorial formula is a count: the number of different groups of r items that can be selected from n available items. It does not name one group, and it is not a probability. In our example, the result three means there are exactly three pairs: A and B, A and C, or B and C.

This is useful when counting choices without listing every possibility. For example, in three dice rolls, choosing which two rolls show a six gives three position-patterns: first and second, first and third, or second and third. The choose-count tells us how many such patterns there are; to find a probability, we would also need to count the possible die values for each pattern and the total outcomes.

A larger example: two six-sided dice

Choose two different face values from the six values on a die. The coefficient counts unordered pairs of face values:

COUNT THE FACE PAIRS(62)=6!2!·4!=15
READ IT ALOUD

Six choose two is six factorial divided by two factorial times four factorial, which equals fifteen different unordered pairs of face values.

For instance, the pair with face values 2 and 5 is one of the 15. When the dice are recorded separately, either die can show either value, so this pair gives two ordered rolls: first die 2 and second die 5, or the reverse. Thus the 15 pairs account for 15×2=30 ordered rolls with different faces.

Those are not all two-dice outcomes: doubles are excluded from the pairs. There are six doubles, one for each face value, so the full count is 30+6=36 ordered outcomes. This example shows why it matters to ask what exactly is being counted.

Two useful edge cases

There is exactly one way to choose nothing: choose the empty group. There is also exactly one way to choose all n items: take the whole group. The formula agrees because zero factorial equals one, as introduced in the factorial lesson.

BOUNDARIES(n0)=(nn)=1
READ IT ALOUD

n choose zero and n choose n each equal one.

See the counts in Pascal’s triangle

Pascal’s triangle arranges binomial coefficients in rows. The top row is row 0, not row 1: it contains (00)=1. Row n has positions from 0 through n. In this explanation, k names the position and number chosen; it plays the same role as r in the formula above.

The outside entries of every row are 1. Each inside entry is the sum of the two entries directly above it. For example, the middle entry 6 in row 4 comes from 3+3=6 in row 3. That gives a quick visual way to build and check the choose-counts.

Where this counting rule is useful

Combinations count groups when order does not matter—for example, which dice show a six, or which people form a team. In the next probability synthesis, this lets us count how many outcomes have a specified number of sixes without listing every possible sequence.

Keep the question in mind

Before using a counting formula, ask whether changing the order creates a genuinely different outcome. If it does, combinations are not the right count.
