MATRICES · ROWS AND COLUMNS

One dot product per cell.

A matrix is a rectangular grid of numbers. Matrix multiplication combines a row from the first grid with a column from the second to make each entry of a new grid.

Read a matrix by row, then column.

We use capital letters for whole matrices. A subscript gives an entry’s position: first its row, then its column. The first row and first column have position 1 in the math notation.

NOTATIONA=[1234],B=[5678]
READ IT ALOUD

Matrix A has rows one, two and three, four. Matrix B has rows five, six and seven, eight.

Matrix shapes are written rows by columns: vertical count first (how many horizontal rows are stacked), horizontal count second (how many entries are in each row). This describes the grid’s entry counts, not its physical height and width on a screen. Each matrix here has two rows and two columns: its shape is “two by two.” For example, A2,1=3 selects row 2, column 1 of A.

First name the result

We want to multiply A by B. Call the resulting matrix C:

RELATIONSHIPC=AB
READ IT ALOUD

C equals A multiplied by B. A and B are the inputs; C is the new matrix we are building.

Next we define what “A times B” means for matrices: each cell of C comes from one row of A dotted with one column of B. C does not already have values; we calculate them one cell at a time. This rule is different from multiplying entries at the same row and column.

Calculate just the top-left cell of C

Take row 1 of A (1, 2) and column 1 of B (5, 7). Match positions, multiply, then add—just as in the dot-product lesson. Using the row and column positions, this is C1,1=A1,1×B1,1+A1,2×B2,1. Now substitute the entries:

ONE CELLC1,1=1×5+2×7=19
READ IT ALOUD

Cell one, one of C is the dot product of A’s first row and B’s first column: one times five plus two times seven equals nineteen.

The dot product gives a single number for this cell of C, not a new row or column.

Repeat for the other three cells

Keep the row fixed while moving to the next column; then move to the next row. Every cell uses a row of A and a column of B:

  • Top right: C1,2=1×6+2×8=22.
  • Bottom left: C2,1=3×5+4×7=43.
  • Bottom right: C2,2=3×6+4×8=50.
RESULTC=AB=[19224350]
READ IT ALOUD

A times B gives C, whose first row is nineteen, twenty-two and second row is forty-three, fifty.

Writing AB here means matrix multiplication, not multiplying entries in the same positions.

The general rule and when shapes fit

The next formula is the same row–column calculation written for any cell of C=AB, not a separate operation. Let A have m rows and p columns. Let B have p rows and n columns. For A times B to be defined, the number of columns in A must equal the number of rows in B. Here both counts are p: every row of A has p entries to pair with the p entries in a column of B. The result C has m rows and n columns. This works for rectangular matrices too, not just squares.

NOTATIONCr,c=∑k=1pAr,k×Bk,c
READ IT ALOUD

For output row r and column c, add the products as k goes from 1 through p: A at row r, column k times B at row k, column c.

The letters r and c choose the output row and column. The index k moves along that row of A and down that column of B; it does not choose a new output cell. In our two-by-two example, p is 2, so each cell adds two products. If A’s column count and B’s row count differ, this matrix product is not defined.

Quick shape check: A’s columns must equal B’s rows

Write each shape as rows by columns. Compare the second number of A (its columns) with the first number of B (its rows). They must be equal. The result uses A’s row count and B’s column count:

SHAPES(m×p)(p×n)→m×n
READ IT ALOUD

A has m rows and p columns. B has p rows and n columns. Because A’s p columns match B’s p rows, the result has m rows and n columns.

For example, if A is two-by-three and B is three-by-four, A has 3 columns and B has 3 rows: they match, so the result is two-by-four. If B were two-by-four instead, its 2 rows would not match A’s 3 columns, so A times B would not be defined. The check predicts only the shape, not the numbers in the result. Reversing the order to B times A would require its own shape check.

A wider row times a taller column

New example: redefine A as two rows by three columns and B as three rows by two columns. The shared size is 3, so each cell adds three products; C has two rows and two columns.

INPUTSA=[123456],B=[789101112]
READ IT ALOUD

A has two rows of three; B has three rows of two. A’s three columns match B’s three rows, so we can multiply them.

Take A’s first row (1, 2, 3) and B’s first column (7, 9, 11):

TOP-LEFT CELLC1,1=1×7+2×9+3×11=58
READ IT ALOUD

One times seven plus two times nine plus three times eleven gives fifty-eight for the top-left cell.

For each remaining cell, choose its row of A and column of B:

  • Top right: C1,2=1×8+2×10+3×12=64.
  • Bottom left: C2,1=4×7+5×9+6×11=139.
  • Bottom right: C2,2=4×8+5×10+6×12=154.
RESULTC=AB=[5864139154]
READ IT ALOUD

A times B gives a two-by-two C with rows fifty-eight, sixty-four and one hundred thirty-nine, one hundred fifty-four.

A different output shape: one column

Start a separate example with new A and B: A has three rows by two columns, B has two rows by one column. A’s two columns match B’s two rows, so C has three rows by one column.

INPUTSA=[123456],B=[23]
READ IT ALOUD

Each of A’s three rows is paired with the single column of B, so C has three entries in one column.

Pair each row of A with the one column of B:

  • First row: C1,1=1×2+2×3=8.
  • Second row: C2,1=3×2+4×3=18.
  • Third row: C3,1=5×2+6×3=28.

All three results belong in the same output column:

RESULTC=AB=[81828]
READ IT ALOUD

A times B produces a column with entries eight, eighteen, and twenty-eight.

The same rule works in every example; changing the outer sizes changes the shape of C, and changing the shared size changes how many products go into each cell.

ALTERNATIVE PYTHON VERSION · AFTER THE EXPLICIT LOOPS

Pair rows and columns with standard-library helpers

This version performs the same row–column dot products, but hides the loops inside Python functions. Read the explicit version first; fewer lines do not guarantee faster execution, and this is not a different multiplication rule. It requires Python 3.12 or later for batched and sumprod.

from itertools import batched, product, starmap
from math import sumprod


def transpose(matrix):
    "Swap rows and columns of a 2-D matrix."
    return zip(*matrix, strict=True)


def matmul(m1, m2):
    "Multiply two matrices."
    columns_count = len(m2[0])  # columns of m2 = columns of C
    pairs = product(m1, transpose(m2))
    cells = starmap(sumprod, pairs)
    return batched(cells, columns_count)


A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]
C = list(matmul(A, B))

for output_row in C:
    print(output_row)  # (19, 22), then (43, 50)

transpose(m2) supplies B’s columns as sequences. product pairs each row of A with each column of B; starmap(sumprod, pairs) computes one dot product per pair. Finally, batched groups consecutive cells into output rows of columns_count cells each.

Unlike the loop’s lists, batched yields tuples, so the printed rows have parentheses rather than square brackets. The numeric matrix is the same. This example assumes nonempty rectangular inputs with A’s column count equal to B’s row count; check those shapes before using it for arbitrary data. sumprod rejects pairs whose lengths differ.

Where this leads

Matrix multiplication appears in coordinate transformations and machine learning. Each cell still follows the row–column rule; those applications can come later.
