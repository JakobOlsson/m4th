VECTORS · DOT PRODUCTS

Match, multiply, and add.

A dot product takes two same-length vectors, multiplies matching components, and adds those products to make one number.

A vector is an ordered list of components.

For this lesson, think of a vector as a list whose entries have a fixed order. The first component matches the first component of another vector, the second matches the second, and so on. We write vector names in bold here to distinguish the whole vector from one component.

Start with two short vectors

Let vector a have components 2 and 3, and vector b have components 4 and 5:

NOTATIONa=(2,3),b=(4,5)
READ IT ALOUD

Vector a has components 2 and 3; vector b has components 4 and 5.

Here, treat these as vectors in the same standard two-dimensional Euclidean coordinate system, with shared x- and y-axes that are perpendicular (at a right angle to each other). The first entry is the component along x; the second is along y. Each vector has two components, so each has dimension 2. The dot product pairs components along the same axis.

The sum-of-products formula here is the ordinary Euclidean dot product in those standard coordinates. The order matters: the first entries are paired, then the second entries.

A vector can go from one point to another

Yes. A vector can describe a displacement: the change from a starting point to an ending point. For example, start at coordinates (1,2) and end at (4,6). Subtract the start coordinates from the end coordinates:

DISPLACEMENT(4,6)−(1,2)=(4−1,6−2)=(3,4)
READ IT ALOUD

End coordinates minus start coordinates give a displacement of three along x and four along y.

The same vector can be drawn as an arrow from the origin to (3,4), or from (1,2) to (4,6). Its components describe the change, not the arrow’s location on the page.

What the dot tells us to do

The centered dot is an operation symbol, not a mark showing a point or place. It tells us to multiply matching components and add the products.

What kind of answer comes out?

A single number, called a scalar. The dot product combines all the component-pairs into that one result.

NOTATION a·b=∑i=1nai×bi
READ IT ALOUD

Vector a dotted with vector b equals the sum, from component 1 through component n, of each a component times its matching b component.

Read each part of the formula

  • a and b are the names of the two vectors.
  • n is the number of components in each vector; their lengths must match.
  • i is the index that selects a matching pair of components.
  • ai,bi are the components at position i.
  • The summation adds the products ai×bi, one product for each position.

The dimension n can be any positive whole number; mathematics sets no fixed maximum. In a computer, memory and time limit how large the vectors can be in practice. Infinite-dimensional spaces also exist, but their dot products need additional rules for infinite sums, which is a later topic.

Expand the two-component example

Pair the first entries, multiply them, then do the same with the second entries:

EXPANDEDa·b=2×4+3×5=8+15=23
READ IT ALOUD

Two times four, plus three times five, equals eight plus fifteen, which is 23.

The answer 23 is one scalar. We do not keep the intermediate products 8 and 15 as a two-component vector.

What does that number tell us?

It summarizes how the matching components combine; it is not a position in space. In this example, both vectors have positive components along the same axes, so their dot product is positive. Move the vectors so their tails share an origin to compare their directions. For nonzero vectors, a zero dot product means a right angle. A negative result means the angle is greater than a right angle; the vectors are exactly opposite only at a straight angle. The size of the result also depends on the vectors’ lengths.

A SHORTER PYTHON VERSION

Use map with the multiplication function

from operator import mul

a = [2, 3]  # math components a_1, a_2
b = [4, 5]  # math components b_1, b_2

dot_product = sum(map(mul, a, b))

print("dot product =", dot_product)

map(mul, a, b) multiplies matching entries from the two lists; sum() adds those products. Unlike the explicit loop, map stops silently at the shorter list, ignoring unmatched entries whether a or b is shorter. Both versions need an equal-length check when used with arbitrary vectors.

Where dot products appear

Dot products are used in geometry, physics, and machine learning. In those settings, they can help describe relationships between vectors; here we focus on the shared component-by-component calculation and leave the broader interpretations for later.
