Powers and roots

Python uses ** for powers, but roots are function calls or fractional powers. The math module provides square root and, in Python 3.11 and later, cube root:

import math

math.sqrt(9)    # 3.0
math.cbrt(-8)   # -2.0 (Python 3.11+)

For a nonnegative x, a general n-th root can be written x ** (1 / n); this usually gives a floating-point approximation. The math module has no general n-th-root function.

Grouping and order of operations

Python follows the familiar arithmetic order: multiplication and division before addition and subtraction. Within * and /, and within + and -, operations group left to right. Parentheses make a different grouping explicit.

2 + 3 * 4       # 14
8 / 4 * 2       # 4: (8 / 4) * 2
8 / (4 * 2)     # 1

A fraction bar groups its numerator and denominator. In Python, if the whole product belongs in the denominator, write a / (b * c)—not a / b * c. Python also has a power/negative-sign gotcha: -2 ** 2 is -4, while (-2) ** 2 is 4.

These basic arithmetic rules are common across programming languages, but rules for other operators can differ. Parentheses are a good way to make your intended grouping clear.

Bit-shift operators such as << and >> are programming topics outside this math refresher.
