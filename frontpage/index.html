WELCOME · THE LEARNING PATH

From reading notation to using it.

This handbook is a guided refresher: first learn what the symbols ask you to do, then see how those operations connect, and finally use them to reason about concrete problems. Lessons unpack the math in words and worked examples; Python is an optional check, not a substitute for understanding the reasoning.

The foundations, step by step

Follow the lesson sequence, or choose a topic directly. Each step builds on earlier ideas and prepares you for later applications.

STEP 01

Learn the language of mathematical notation

Learn what letters represent in mathematical formulas. Then read a sum by its starting and ending values, changing index, and term being added. Products and factorials introduce the parallel operation of multiplication.

  • Letters and notation — Common symbol roles and mathematical vocabulary.
  • Summation — Translate ∑ into additions and a loop.
  • Products and factorials — Read ∏ as repeated multiplication, including n!.
STEP 02

Use notation to answer probability and counting questions

Use sums to combine event probabilities and calculate weighted averages. Then count possible groups and outcomes, and measure how much work an algorithm performs.

  • Probability — Outcomes, events, and probability notation.
  • Expected value — A probability-weighted average.
  • Probability bounds — Bound the chance of overlapping events.
  • Counting work — Connect loops and recursion to algorithm growth.
  • Combinations — Count groups when order does not matter; Pascal’s triangle helps build the counts.
STEP 03

Connect mathematical structures and justify results

A dot product is a sum of products, and matrix multiplication uses a dot product for each result cell. Program correctness and induction help explain why an algorithm works, not just whether it passed a few tests.

  • Vectors and dot products — Multiply corresponding components, then add.
  • Matrix multiplication — Calculate each result cell from a row and a column.
  • Program correctness — State assumptions, promised results, and loop invariants.
  • Proof by induction — Prove a starting case and show each case leads to the next.

How the ideas tie together

Operations form more complex expressions

A sum can add factorials or probabilities. The summation instruction stays the same; the term being added changes.

See the sum-of-factorials example

Counting helps calculate probability

A combination counts which positions or items meet a condition. Pair that count with the possible outcomes to calculate a probability.

The dice-probability lesson counts the outcomes with at least two sixes.

Simple operations build larger structures

Each matrix-product cell is a dot product: multiply matching values in a row and column, then add.

See matrix multiplication

Checking and proving are different

Python can check selected inputs. Loop invariants and induction explain why a result holds for every input covered by the assumptions.

Explore program correctness
