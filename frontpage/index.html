FIRST NOTATION · SUMMATION SIGN (∑)

A sum is an instruction to add terms.

The lower limit gives the starting index; the upper limit gives the last index included. The expression beside the sum tells us what to add for each index.

NOTATION
n ∑ i = 1 i
READ IT ALOUD

Add each value of i from one through n.

Same notation, different layout

The summation sign ∑ is based on the capital Greek letter Sigma (Σ). In displayed equations, its limits are commonly placed above and below. Inline, they are often placed to the right to save space:

Inline: ∑i=1n ai

Both layouts mean: add the terms ai for indices from 1 through n. Typesetting conventions can vary.

The bounds

i = 1 is where the index starts. n is where it stops. If n = 4, the index takes the values 1, 2, 3, and 4.

Index vs. term

Here, i is both the index and the value being added. That is not always true: in ∑i=1n ai, i selects a position and ai is the term added.

The starting bound depends on what you want to add

The limits are part of the instruction: choose the first and last indices that belong in the sum. They are not always 1 and n.

Start at 0:

∑i=03 ai = a0 + a1 + a2 + a3

Read aloud: Add a0, then a1, a2, and a3.

Start at 2:

∑i=24 ai = a2 + a3 + a4

Read aloud: Add a2, then a3 and a4.

Here is a probability preview: P(A) means “the probability that A happens.” Let X be a count that can be any integer from 0 through n; P(X = k) is the probability that the count equals k. For a full introduction, see the probability lesson.

For “at least 2,” add the probabilities for outcomes 2 through n:

NOTATION

P(X ≥ 2) = ∑k=2n P(X = k)

READ IT ALOUD

The probability that X is at least 2 is the sum of the probabilities that X equals 2, 3, and so on through n.

Expanded, that is P(X=2) + P(X=3) + ⋯ + P(X=n). “Exactly 2” is just P(X = 2).

By contrast, “at most 2” uses outcomes 0 through 2:

NOTATION

P(X ≤ 2) = ∑k=02 P(X=k)

READ IT ALOUD

The probability that X is at most 2 is the sum of the probabilities that X equals 0, 1, or 2.

For separated outcomes, sum over a set of indices rather than an interval.

TRY A SMALL VALUE

Let n = 4

∑i=14 i = 1 + 2 + 3 + 4 = 10

THE SHORTER, IDIOMATIC PYTHON VERSION

Let Python do the repeated addition

For a simple sum over a sequence, Python’s built-in sum() function is a concise way to add the values:

n = 4
i = 1
total = sum(range(i, n + 1))
print(total)

range(i, n + 1) produces the index values from i through n. Python stops before the range’s end value, so we use n + 1 to include n. Then sum() adds those values. It’s the same calculation as the loop above, with the repeated addition tucked into a built-in function.

Where this leads

The same summation notation appears in probability, dot products, and matrix multiplication. We’ll return to those later; for now, we’re practicing how to read the sum itself. The handbook will use English mathematical terminology throughout.
