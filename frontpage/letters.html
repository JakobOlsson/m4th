A QUICK GUIDE · MATHEMATICAL LETTERS

Letters are names. Context gives them a job.

Math uses familiar letters as compact labels for numbers, positions, functions, and other objects. Some letter choices are common conventions—but they are clues, not unbreakable rules.

Common patterns you may recognize

These patterns can help you get oriented. Always check how the author defines the symbols.

LettersOften used forExample role
x, y, zVariables or unknown valuesThe value we want to find or vary
a, b, cConstants, parameters, or coefficientsA value treated as fixed in a particular problem
i, j, kIndices or countersA position that changes as we move through a sequence
m, nSizes, counts, or boundsThe number of items or an upper limit
f, gFunctionsA rule that takes an input and produces an output
FnTerms in a named sequenceIn the Fibonacci example, F names the sequence and n selects a term.
No letters are off-limits.

An author can define x as a vector, use i as an ordinary index, or give a familiar letter a different role. The definitions and surrounding expression determine what a symbol means—not the letter by itself.

FUNCTION NOTATION

What does f(x) say?

NOTATION
y=f(x)=x+2 Substitute x = 3 y=f(3)=3+2=5
READ IT ALOUD

y equals f of x. The function adds 2 to its input. When x is 3, y is 5.

  • f is the name of the function (the rule).
  • x is the input given to the function.
  • y names the output, so y = f(x) says that y depends on x through the rule f.

In typeset math, variables and function names such as x and f are commonly italic. Names of standard operations such as sin and log are commonly upright. Typography can help, but definitions still matter.

FAMILIAR LETTERS WITH SPECIAL USES

Conventions can overlap

Some letters have especially familiar meanings in particular topics:

  • i often labels an index; in complex numbers, i is the imaginary unit.
  • e often denotes the number used as the base of natural logarithms (about 2.718).
  • π often denotes the circle constant (about 3.142).
NOTATIONi2=−1
READ IT ALOUD

i squared equals negative one.

These uses do not make the letters forbidden for other purposes. If a paper uses the same symbol in different roles, its definitions and context should make the intended meaning clear.

ALGORITHM GROWTH NOTATION

Big O, theta, and cases

In the counting-work lesson, Big O describes an upper bound on how an algorithm’s work grows. For a loop that makes n passes, O(n) is an upper bound. The symbol Θ(n) (“theta”) says the growth is tightly bounded by n from above and below.

Best case, worst case, and average case describe which inputs are being measured; they are not alternative Big O symbols. An average case is based on an assumed distribution of inputs, not just the most common input. The counting-work lesson gives a fuller explanation.

A PREVIEW · PROBABILITY NOTATION

Probability notation

NOTATIONP(X=k)
READ IT ALOUD

The probability that X equals k.

P(A) is commonly read as “the probability that event A happens.” An uppercase letter such as X often names a random variable—a value that depends on the outcome of a chance process. So P(X=k) means “the probability that X has the value k.”

This is a quick preview; see the probability lesson for a first worked example. In the summation lesson, this notation shows what probabilities are being added.

LETTERS DO NOT TELL THE WHOLE TYPE

Scalar, vector, or matrix?

A symbol does not tell us by itself what kind of mathematical object it represents. A scalar is a single value; a vector is a list of components; a matrix is a grid of values. Authors often use bold letters for vectors and capital letters for matrices, but conventions vary—look for the definitions.

Glossary: Euclidean coordinate system

A Euclidean coordinate system describes points or vectors by components along perpendicular axes—x and y in two dimensions. Perpendicular means the axes meet at a right angle to each other. Standard Euclidean coordinates use the same unit scale on each axis, so the familiar rules for distance and angle apply. A displacement vector records the change from a start point to an end point: subtract the start coordinates from the end coordinates. The arrow can be drawn anywhere; its components describe the change, not its location. The dot-product example uses two-dimensional Euclidean coordinates: matching components refer to the same axis.

Matrix positions and dimensions

A matrix shape is written rows by columns: number of horizontal rows stacked vertically first, then number of entries across each row. In matrix multiplication, uppercase A and B name input matrices and C names the result. Ar,k means the entry in row r, column k of A: the first subscript position selects the row, the second selects the column. Here m counts A’s rows, p counts its columns and B’s rows (the shared dimension), and n counts B’s columns. The output cell Cr,c is at row r, column c; the index k moves through the matching entries to calculate that cell. These letters describe roles here, not universal naming rules.

What does Rd mean?

The symbol ℝ (read “the real numbers”) means the set of ordinary real-number values. Rd means the space of all vectors with d real-number components; the superscript is the dimension, not an exponent on a particular vector. For example, u∈R3 says that u is a three-component vector.

Transpose: the superscript T

The superscript transpose symbol means swap rows and columns. If vectors are written as columns, u=[23] is a column and u⊤=[2,3] is a row. The mark tells us to perform that swap; it is not just a label for “this is a vector.”

Key and value: roles in a lookup

A key is information used to look up a stored item; its associated value is the information we want back. As a simple analogy, a person’s name could be a key and their phone number its value. In a vector-based memory, both may be represented by vectors: the key vector describes a pattern to match, and the value vector holds the associated information. A query is what we search with; it is compared with the keys, and a good match retrieves the associated value. “Key” and “value” describe roles in this lookup example; they are not special kinds of vectors.

Outer product: column times row

Multiplying a column vector by a row vector makes a matrix called an outer product. For a two-component value v=[57] and key k=[23], first transpose the key to make it a row:

k⊤=[2,3]

Now multiply each entry in the value column by the whole key row. The first value, 5, makes the first row; the second value, 7, makes the second row:

5×[2,3]=[5×2,5×3]=[10,15],7×[2,3]=[14,21]. Put those rows together:

vk⊤=[10151421]

So the result has two rows (one per value component) and two columns (one per key component). Each entry is one value-component multiplied by one key-component. This is different from the dot product k⊤x, which is a single number. In fact, (vk⊤)x=v(k⊤x): compare the query x with key k to get one match score, then use it to scale the stored value v. To store several key–value associations this way, add their outer-product matrices; the resulting matrix is called a memory matrix.

The same rule works in any key dimension

The query x and key k must have the same number of components so their dot product is defined. In one dimension, k=[2],x=[3],k⊤x=2×3=6. In two dimensions, k⊤x=2×3+1×4=10.

In general, if k,x∈Rdk, then k⊤x=∑j=1dkkjxj: multiply matching components and add them. This single number measures how strongly the query matches the key. The value v can have a different number of components, v∈Rdv, and the retrieved output then has that value dimension. Here dk is the key/query dimension; if there are M stored key–value pairs, M counts the pairs, not the components in a vector.

Normalizing a vector to length 1

A vector’s length is also called its norm. In the usual Euclidean geometry, its length is found by extending the Pythagorean theorem to every component: square each component, add the squares, then take the square root. For k=[k1,…,kd]⊤, this is ‖k‖=k12+⋯+kd2. Components can be negative: [−3,4]⊤ has length 5, because the components are squared. Normalizing a nonzero vector means dividing every component by its length; this keeps its direction (including any negative components) but makes its length 1. For example, k=[3,4]⊤,k^=[35,45]⊤. If a key has been normalized, k⊤k=1. Therefore, when a query is exactly that key, the key’s match score is 1.

See the index in action

In the summation ∑i=1nai, i is the index, n is the upper bound, and ai is the term added at each step.
