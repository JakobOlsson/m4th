SYNTHESIS · SUMS AND FACTORIALS

When each term is a factorial

We have already learned how to add indexed terms and how factorials multiply positive integers. Now we put those ideas together: the index chooses a value, and the whole factorial of that value is the term we add.

SUBJECTS USEDSummationFactorialsTaylor series

Read the whole summand at each index.

In summation notation, the bounds tell us which values the index takes. The expression beside the sigma sign tells us what to calculate at each value. Here that expression is k factorial, introduced in the factorial lesson.

EXAMPLE∑k=14k!
READ IT ALOUD

Add the factorials of the integers from one through four.

First substitute each index value

The index k takes the values 1, 2, 3, and 4. At each step, replace k in the whole term k!; do not add just the index values.

EXPAND∑k=14k!=1!+2!+3!+4!
READ IT ALOUD

One factorial, plus two factorial, plus three factorial, plus four factorial.

Now expand each factorial as a product. The factorial marks the end of a multiplication sequence down to one:

Index kTerm k!Value added

Add the four values: 1 + 2 + 6 + 24 = 33. So the sum of factorials is 33. Notice the two layers of work: each factorial multiplies, and the outer sum adds those factorial values.

RESULT∑k=14k!=1+2+6+24=33
READ IT ALOUD

The factorial terms evaluate to one, two, six, and twenty-four; their sum is thirty-three.

How the two layers become loops

The outer loop chooses k, the value whose factorial is the next term. The inner loop multiplies from 1 through k to calculate that factorial; factor is its changing counter. Python's range stops before its upper bound, so n + 1 and k + 1 make the loops include 4 and k, respectively. Then the outer loop adds the completed term to total. The inner multiplication starts at 1 because 1 leaves a product unchanged; the outer sum starts at 0 because adding 0 leaves a total unchanged.

EXTENSION · TAYLOR SERIES

A factorial series can approximate sine

A Taylor series is an infinite sum of terms that represents a function. Sine values are useful in rotation, geometry, and periodic-motion calculations; the series gives us a clear example of a numerical approximation. For sine, the series around zero uses alternating signs, odd powers of x, and factorials in the denominators. Here x is measured in radians; this series converges to sin(x) for every real x.

INFINITE SERIESsin(x)=∑k=0∞(−1)kx2k+1(2k+1)!=x−x33!+x55!−x77!+⋯
READ IT ALOUD

Sine of x is the infinite sum, as k runs from zero upward, of alternating odd powers of x divided by their odd factorials.

The infinity symbol means there is no final term in the exact series. A computer cannot add infinitely many terms, so it calculates a partial sum—a finite beginning of the series. If K is the last index we include, then indices 0 through K give K + 1 terms:

FINITE APPROXIMATIONSK(1)=∑k=0K(−1)k(2k+1)!
READ IT ALOUD

Add the terms from index zero through K to approximate sine of one radian.

For a concrete value, take x = 1 radian. The first terms build the approximation step by step:

The value from a standard calculator is sin(1)≈0.8414709848. The partial sum after K = 2 is already close, but how close can we guarantee it is?

For x = 1, the terms alternate in sign and shrink in size. The alternating-series error bound says the difference from the exact value is no larger than the first term left out. After K = 2, the first omitted term is 17!=15040≈0.0001984. So three terms, ending at K = 2, guarantee an error smaller than 0.0002 for this example. If we want a tighter tolerance, we increase the upper bound. This error-bound fact is a brief preview; we are using it here, not proving the general alternating-series theorem.

The source notes also point to the exponential Taylor series, which uses the same factorial denominators but all nonnegative powers:

Here k is the summation index, and e is the constant described in the letters guide. At k = 0, the first term is x00!=1, using x0 = 1 and 0! = 1. This is a related example, not a derivation of the series.

Scope: this shows how an infinite formula becomes a finite numerical approximation. The sine series is exact as an infinite sum; a finite partial sum is an approximation. OPTIONAL TAYLOR-SERIES CHECK

Choose a tolerance, then stop

For x = 1, the alternating-term bound gives a principled stopping test: keep adding terms until the first omitted term is smaller than the chosen tolerance. This code is a separate optional version of the editor example.

Optional Python check · Taylor series for sin(1)

Load this version to add terms until the first omitted term is below tolerance. Here k is the series index, power is 2 * k + 1, and factorial(power) supplies the denominator. math.sin is used only as a comparison value.

from math import factorial, sin

x = 1.0  # radians
tolerance = 1e-8
approximation = 0.0
k = 0

while True:
    power = 2 * k + 1
    term = ((-1) ** k) * (x ** power) / factorial(power)
    approximation = approximation + term

    next_k = k + 1
    next_power = 2 * next_k + 1
    first_omitted_term = abs(x ** next_power / factorial(next_power))
    if first_omitted_term < tolerance:
        break
    k = next_k

print("last included index =", k)
print("terms included =", k + 1)
print("Taylor approximation =", format(approximation, ".12f"))
print("math.sin check =", format(sin(x), ".12f"))
print("first omitted term bound =", first_omitted_term)

A reusable way to read a more complex sum

  1. Read the bounds to find the index values.
  2. Substitute each index into the entire summand.
  3. Evaluate each term, then combine the terms using the sum's operation.

The same approach works when the term is a power, a probability, or another expression: first expand a few terms explicitly so it is clear what the index changes and what gets added.

Where this leads

This is a first example of a sum whose terms are themselves calculated expressions. The same pattern appears in probability formulas and in sums of products, where each term may take more unpacking.
