EXPECTED VALUE · A WEIGHTED AVERAGE

A likely long-run average, not a promised outcome.

Probability tells us the chance of each result. Expected value combines each result with its chance to describe the distribution’s average.

Weight each outcome by its probability.

Roll one fair six-sided die. Let X be the number shown. Each result k from 1 through 6 has probability 1/6.

NOTATION E[X]=∑k=16kP(X=k)

E[X] names the expected value of X.

READ IT ALOUD

“The expected value of X is the sum, as k goes from one through six, of k times the probability that X equals k.”

What the instruction does

For each possible result, multiply the result by its probability. Then add those weighted results. Because the die is fair, each weight here is 1/6.

Substitute each outcome into the term

The whole summand is kP(X=k). Substitute each value of k, just as we did with the probability term in the previous lesson:

EXPANDED, THEN EVALUATED E[X]=1×16+2×16+3×16+4×16+5×16+6×16=216=72=3.5
READ IT ALOUD

“Add one times one sixth, two times one sixth, and so on through six times one sixth. The total is twenty-one sixths, or seven halves, which is three point five.”

The expected value need not be a possible roll.

A single die roll can never be 3.5. The expected value is the probability-weighted average of possible results. Over many independent rolls, the observed average tends to settle near 3.5, though any finite batch can be above or below it.

This example does not assume a normal distribution: one die roll has six equally likely whole-number outcomes. A normal distribution is a different, continuous, bell-shaped model. Expected value applies to both, though a continuous distribution uses an integral instead of this finite sum. Why averages of many rolls can be approximately normal is a separate topic.

The same mean can hide different spreads

Imagine two separate toy draws, each from three equally likely labeled slips. In the first draw, the slips show 2, 3, or 4; name the resulting random value U. In the second, they show 1, 3, or 5; call the result V. These are random values in the same sense that X names a die result above. Each set has the same expected value: add its three outcomes and divide by 3 because each has probability one third.

SAME MEAN
E[U]=2+3+43=3
E[V]=1+3+53=3
READ IT ALOUD

Both draws have expected value three: the three possible outcomes add to nine, and each is equally likely, so each average is nine divided by three.

The dot plots suggest that V is more spread out, but the shared mean cannot quantify that difference. Measure each outcome’s distance from its own mean of 3, square it (so negative and positive differences do not cancel), then take the probability-weighted average of those squared distances. For example, U’s outcome 2 contributes (2−3)2=1; V’s outcome 1 contributes (1−3)2=4. At the mean, the squared distance is zero; the other outer outcome in each set gives the same squared distance as its first.

SQUARED DISTANCES, THEN VARIANCE
Var(U)=(2−3)2+(3−3)2+(4−3)23
Var(U)=1+0+13=23
Var(V)=(1−3)2+(3−3)2+(5−3)23
Var(V)=4+0+43=83
READ IT ALOUD

Variance is the average squared distance from the mean. For U, add one, zero, one and divide by three: two thirds. For V, add four, zero, four and divide by three: eight thirds. V’s variance is larger even though their means match.

These are population variances of the two fully specified toy distributions, not estimates from three observations. A variance uses squared units—if the outcomes measured tokens, the variances would be in tokens squared. To return to the original units, take the square root: that is the standard deviation.

STANDARD DEVIATION
σU=Var(U)=23≈0.816
σV=Var(V)=83≈1.633
READ IT ALOUD

U’s standard deviation is the square root of two thirds, about 0.816; V’s is the square root of eight thirds, about 1.633. These describe the distributions’ spread in the original units, not a guaranteed distance for any one draw.

For any random value W with a finite mean and finite variance, call its mean μ=E[W]. W may stand for U or V above; unlike the small example, its possible values need not be equally likely. The expected-value rule supplies the appropriate weights. Generalizing the same steps gives:

GENERAL RELATIONSHIPVar(W)=E[(W−μ)2],σW=Var(W)
READ IT ALOUD

The variance of W is the expected value of its squared distance from its mean mu; the standard deviation of W is the square root of that variance. Use each possible outcome’s probability as its weight.

If every possible outcome equals its mean, variance and standard deviation are zero; neither can be negative. Unlike a sample-based estimate, these exact values follow from the stated outcome probabilities. The example’s equality of means alone could not tell us which distribution was more spread out.

A second use: the net result of a game

Consider an explicitly hypothetical game: a ticket costs 2 tokens. Roll one fair six-sided die. A six pays 6 tokens; any other face pays 0. We want the expected net result per ticket, not the expected die face. Let Y name the tokens received minus the ticket cost. Build its possible values from the rules:

Hypothetical one-roll game, in tokens
Die resultPayoutCostNet YProbability
Six62+41/6
Any of the other five faces02−25/6

The two cases are disjoint and cover all six equally likely faces. Weight each possible net result by its probability and add; this is the same expected-value instruction as for the die face:

EXPECTED NET RESULTE[Y]=4×16+(−2)×56=46−106=−1
READ IT ALOUD

Four tokens of net gain times a one-in-six chance, plus two tokens of net loss times a five-in-six chance, gives an expected net loss of one token per ticket.

The expected net result is −1 token per ticket under these rules. A single ticket instead produces either +4 or −2, never −1. This average is not a guarantee about any particular ticket, and it is not a claim about real-world games. A SHORTCUT THAT DEPENDS ON THIS MODEL

For a fair die, this is also the ordinary average.

Because all six outcomes have the same probability, their expected value is their arithmetic mean. This shortcut would not work for an unfair die; the weighted-sum formula is the general instruction.

from fractions import Fraction

possible_k_values = range(1, 7)  # possible values of k
expected_value = Fraction(sum(possible_k_values), len(possible_k_values))  # E[X] for fair die
print(expected_value)  # 7/2

CHECK THE LONG-RUN AVERAGE

A simulation estimates the expected value too.

The exact expected value is 3.5. Repeatedly roll the die and average the results to see the sample mean fluctuate around that theoretical value. This is a simulation check, not the derivation of the exact expectation.

RollsSimulated averageExact expected value
1003.43.5
1,0003.5753.5
10,0003.49823.5
 
import random

rng = random.Random(2027)
total = 0  # running sum of x values
for trial in range(1, 10_001):
    x = rng.randint(1, 6)  # x = observed X
    total = total + x
    if trial in (100, 1_000, 10_000):
        print("Rolls:", trial, "average:", round(total / trial, 4))

Interpretation: the observed averages need not move closer at every checkpoint. The expected value describes the distribution; it is not a promise about one short run.

Where this leads

Expected values appear in games, risk analysis, and machine learning. A non-uniform distribution uses its actual outcome probabilities as weights in both expected value and variance; the equal-likelihood shortcut and the two dot plots above do not replace those weights.
