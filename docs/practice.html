Practice sessions

These short activities are separate from the core lesson sequence. Try the problem on paper first; open a hint or worked explanation when you want one. Python checks appear only when they add something useful.

A different way to learn

Some sessions use familiar settings such as dice or cards; others ask you to prove a mathematical claim. The goal is not to rush to code, but to explain why each step follows. Visuals can help with small cases, and a counting argument can carry the idea beyond what is easy to picture.
