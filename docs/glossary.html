Reading sums and products

Index

A changing label that visits the positions or values included in a sum or product.

In ∑k=13k, k is the index.

Summation lesson

Summand

The whole expression being added on each pass through a sum.

In ∑k=14k!, the summand is k!, not just k.

Sum-of-factorials lesson

Bounds

The starting and ending values that tell an index which values to visit.

“From one through four” includes 1, 2, 3, and 4.

Summation lesson

Factorial

For a positive whole number, multiply all positive integers up to that number. Zero factorial is defined as one.

4!=4×3×2×1=24

Products and factorials

Gamma function

A standard function used to extend factorial notation beyond nonnegative integers. In the positive range shown in this handbook, x! = Γ(x + 1); its recurrence makes the graph agree with ordinary factorials at integer inputs. This is a preview, not a derivation of the function.

(12)!=Γ(32)=π2.

Gamma graph in the factorial lesson

Power (exponent)

The exponent tells how many times the base is used as a factor. For a positive whole-number exponent, this means repeated multiplication; a nonzero base to the zero power equals one.

(16)2=136.

Dice-probability lesson

Absolute value

For a real number, its nonnegative distance from zero.

|−7|=7.

Bar-notation comparison

Empty sum

A sum with no terms. Its value is zero, the value that leaves an addition total unchanged.

If a loop adds no numbers, its total remains zero.

Program-correctness lesson

Logarithm (base two)

The exponent needed on 2 to obtain a positive input; a log need not be a whole-number count of steps.

23=8⟺log28=3.

Halving comparison

Empty product

A product with no factors. Its value is one, the value that leaves a multiplication result unchanged.

In the Bézier coefficient formula, ∏m=0j−1(n−m) has no factors when j = 0, so its value is 1.

Sets and counting

Set

A collection of distinct items. The order in which items are written does not change the set.

{A,B,C} names the set of three letters.

Combinations lesson

Subset

A set whose members all come from another set; it may contain some or all of the original items.

The pair {A,C} is a subset of {A,B,C}.Combinations lesson

Membership

A relation that says whether an item belongs to a set. Use the membership symbol for “is in” and a crossed version for “is not in.”

2∈S,4∉S.

Letters and notation

Set-builder notation

Describe a set by a starting collection and a condition each member must satisfy.

From S={1,2,3}, keeping members greater than 1 gives 2 and 3.

Set-builder example

Set union

The set of items that belong to either of two sets, including items that belong to both.

A∪B={1,2,3}.

Letters and notation

Set intersection

The set of items shared by both sets.

A∩B={2}.

Letters and notation

Cardinality

The number of members in a set. Vertical bars around a set can denote its cardinality; context distinguishes this from absolute value.

|S|=3.

Letters and notation

Empty set

The set with no members.

∅.

Letters and notation

Common number sets

Standard sets group numbers by their properties: natural numbers, integers, rational numbers, real numbers, and complex numbers.

ℕ,ℤ,ℚ,ℝ,ℂ.

Letters and notation

Combination

A choice of a specified number of items where changing their order does not make a new choice.

Choosing A and B is the same combination as choosing B and A.

Combinations lesson

Ordered selection

A selection where the order of the chosen items is counted. The same items in a different order count as a different selection.

AB and BA are two ordered selections but one combination.

Combinations lesson

Permutation

An arrangement or selection where changing the order counts as a different result. Arranging all n distinct items gives n! orders; choosing only r in order gives P(n,r)=n!(n−r)!.

Three different books have 3!=6 possible shelf orders.

Factorial permutation example

Coefficient

A quantity that multiplies another quantity. It is often a number, but in a vector-valued polynomial it can be a vector. In 3x, 3 is the numerical coefficient of x.

Combinations lesson · Bézier-curve lesson

Binomial

A polynomial with exactly two nonzero terms, joined by addition or subtraction.

The expression x+y is a binomial. If x=1,y=−1, its value is zero.

Combinations lesson · Bézier-curve lesson

Binomial coefficient

The number of ways to choose r items from n distinct items. Its value is a count of groups, not a probability or one particular group. It is called a coefficient because these numbers also multiply terms when powers of a binomial are multiplied out.

(32)=3: there are three pairs in a set of three items.

Combinations lesson

Pascal’s triangle

A triangular arrangement of binomial coefficients. Start with row zero containing one; each new row begins and ends with one, and each inside entry is the sum of the two above it.

Row 3 is 1, 3, 3, 1; its entry at position 2 is (32)=3.

Combinations lesson

Probability

Outcome

One possible result of a chance process.

One roll of a die can produce 1, 2, 3, 4, 5, or 6.

Probability lesson

Event

A collection of outcomes that meet a condition we care about.

“The roll is even” is the event {2,4,6}.

Probability lesson

Conditional probability

The chance of an event after learning another event happened; restrict attention to the outcomes consistent with that information.

Given an even die roll, 2 of the 3 remaining faces are at least 4.

Conditional-probability lesson

Bayes’ rule

A way to reverse which event is given, by counting their shared outcomes relative to the newly given event.

Of 5 starred tickets, 3 are red, even though 3 of 4 red tickets have stars.

Ticket example

Independent events

Two events are independent when knowing whether one happened does not change the probability of the other.

For independent die rolls, the first result does not change the chances on the next roll.

Dice-probability lesson

Random variable

A quantity whose value depends on the outcome of a chance process.

A die roll can be named by the random variable X.

Probability lesson

Expected value

The probability-weighted average of a random variable's possible values. It need not be a value that can occur in one trial.

For a fair six-sided die, the expected roll is 3.5.

Expected-value lesson

Variance

The probability-weighted average of squared distances from a distribution’s mean; it measures spread in squared units, not uncertainty about the mean.

Equally likely 2, 3, 4 have variance two thirds, while 1, 3, 5 have variance eight thirds; both have mean 3.

Same mean, different spread

Standard deviation

The square root of variance; it describes spread in the same units as the outcomes.

The square root of two thirds is about 0.816 for the first toy distribution.

Spread comparison

Union bound

The probability that at least one of several events happens is no more than the sum of their individual probabilities. The events do not need to be independent.

Adding event probabilities can give a safe upper bound, even if events overlap.

Probability-bounds lesson

Monte Carlo method / simulation

Use repeated random samples to estimate a probability or another quantity that is difficult to calculate exactly. More samples can reduce sampling noise, but the result still depends on the model and its assumptions.

A simulation is evidence about a model's behavior, not a proof that the model or its assumptions are correct.

Probability lesson · Dice simulation · π estimation example

Vectors and matrices

Vector

An ordered list of components, often used to represent a direction or a collection of numerical features.

A two-component vector has a first and a second value.

Vectors and dot products

Vocabulary (in a word-count model)

A fixed list of distinct words used as coordinates for every text being compared. Each vector entry counts occurrences of the corresponding word in that same order.

With the vocabulary cats, chase, mice, birds, “cats chase mice” gives (1,1,1,0).

Construct the word-count vectors

Vector length (norm)

For the ordinary Euclidean length, square each component, add the squares, and take the square root. A zero vector has length zero and cannot be used in cosine similarity's denominator.

The length of (1,1,1,0) is 3.

Read the double bars · Word-count vector lengths

Matrix norm (preview)

A nonnegative measure of a matrix’s size under a chosen rule; different matrix norms need not give the same value. Double bars alone do not say which rule to use.

For a two-by-two matrix M, a value for its norm requires both the entries and a specified norm.

Bar-notation comparison

Cosine similarity

For two nonzero vectors, divide their dot product by the product of their lengths. It compares the direction of their count patterns rather than the raw number of matching words. Nonnegative count vectors give a score from 0 to 1; arbitrary vectors can give negative scores.

Two word-count vectors with dot product 2 and lengths both 3 have cosine similarity 23. This score is not a probability or a guarantee of shared meaning.

Cosine example

Component

One value or coordinate inside a vector.

In a two-component vector, the first and second coordinates are its components.

Vectors and dot products

Vector coefficient

A vector that multiplies a scalar in a vector-valued polynomial. The scalar scales each component, and the resulting vectors are added component by component; it is not a product of two vectors.

In the Bézier power form, if C1=(4,4), then tC1=(4t,4t).

Bézier-curve lesson

Scalar

A single number, as opposed to a list of numbers such as a vector.

A dot product of two vectors is a scalar.

Vectors and dot products

Dot product

Multiply corresponding components of two equal-length vectors and add the products.

For vectors (2,3) and (4,5), the dot product adds matching component-products to give 23.

Vectors and dot products

Weighted sum

A total made by multiplying each input by a corresponding weight, then adding those products.

4×3+2×4=20 is proposal A's weighted score when its ratings are 4 and 2 and the criterion weights are 3 and 4.

Weighted-scoring lesson

Matrix

A rectangular arrangement of numbers in rows and columns.

A matrix's shape is described by its number of rows and columns.

Matrix-multiplication lesson

Identity matrix

A square matrix with ones on its diagonal and zeros elsewhere; multiplying a compatible matrix by it leaves that matrix unchanged.

The two-by-two identity has first row one, zero and second row zero, one.

Matrix-multiplication example

Perpendicular

At a right angle to each other.

In the usual coordinate plane, the horizontal and vertical axes are perpendicular.

Series and approximation

Taylor series

An infinite sum of powers used to represent a function around a chosen input value. A finite partial sum can approximate the function; how many terms are needed depends on the input and the accuracy wanted.

For sine around zero, the terms alternate and have odd powers of the input, divided by odd factorials.

Sine Taylor-series example

Curves and graphics

Bézier curve

A smooth path described by a parameter and a sequence of control points. Moving the control points changes the curve.

A quadratic Bézier curve uses three control points; its path starts at the first and ends at the last.

Bézier-curve lesson

Polynomial

A finite sum or difference of terms. In a single-variable example, a term is a coefficient times the variable raised to a nonnegative whole-number power (0, 1, 2, and so on).

The term-count names are special cases: one term is a monomial, two terms a binomial, and three terms a trinomial. Each is still a polynomial; expressions with more terms are usually just called polynomials.

4t−4t2 is a binomial because it has two terms; t2+3t+2 is a trinomial because it has three.

Bézier-curve lesson

Polynomial degree

For a nonzero polynomial, the degree is the largest exponent with a nonzero coefficient. A Bézier curve's degree is the degree of its polynomial form; it counts powers, not angles.

4t−4t2 has degree 2 because the largest exponent is 2. A degree-2 Bézier curve uses 3 control points: one more than its degree.

Bézier-curve lesson

Monomial

A polynomial with exactly one nonzero term.

7t2 is a monomial.

Bézier-curve lesson

Trinomial

A polynomial with exactly three nonzero terms.

t2+3t+2 is a trinomial.

Bézier-curve lesson

Control point

A point that helps shape a Bézier curve. The first and last are its endpoints; middle control points guide the path but need not lie on it.

The middle point of a quadratic curve pulls its path but is not generally on the curve.

Bézier-curve lesson

Bernstein basis

The set of parameter-dependent weights used to combine control points in the Bézier formula. For a parameter from 0 to 1, the weights are nonnegative and sum to 1.

For a quadratic curve at t=12, the three weights are 14,12,14.

Bézier-curve lesson

Algorithms and proof

Big O

A notation for an upper bound on how quickly a quantity grows, such as the work an algorithm does as input size increases.

O(n) is an upper bound proportional to n. A method that checks every ordering of n items has n! candidates, which motivates O(n!) growth; this notation is an upper bound, not a promise that every input checks exactly n! cases.

Counting-work lesson · Factorial-growth example

Precondition

An assumption about the input that must hold before a program runs.

The summation loop requires its input to be a nonnegative integer.

Program-correctness lesson

Postcondition

A statement about the result that a program promises when it finishes.

After the summation loop, total should equal the requested sum.

Program-correctness lesson

Loop invariant

A claim that is true before every pass through a loop. A proof checks that it starts true and stays true.

The running total equals the sum of the values already added.

Program-correctness lesson

Induction hypothesis

A temporary assumption that a claim is true at an arbitrary integer k, used to prove it at the next integer.

Assume the claim at k; show it follows at the next integer.
