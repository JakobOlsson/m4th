NEXT NOTATION · PRODUCT (∏)

A product is a sum’s multiplication twin.

Summation tells us to add a sequence of terms. Product notation gives the parallel instruction: multiply the terms together.

Read the bounds, then multiply each term.

Just like a sum, the lower bound says where the index starts, the upper bound says where it ends, and the expression beside the operator says what to use at each step.

NOTATION
∏i=1ni
READ IT ALOUD

Multiply each value of i from one through n.

The symbol

∏ is the product symbol, based on the capital Greek letter Pi (Π). It is different from lowercase pi (π), the circle constant.

Same bounds, different action

∑ adds the terms. ∏ multiplies them. The index i and bounds work the same way in both.

Let n = 4

Now the index takes the values 1, 2, 3, and 4. Instead of adding them, multiply them:

EXPANDED∏i=14i=1×2×3×4=24
READ IT ALOUD

Multiply the integers from one through four; the result is 24.

FACTORIAL NOTATION

The exclamation mark means “factorial.”

For a positive whole number, the factorial multiplies every positive integer from that number down to 1. So 4! is another way to write the product we just expanded:

NOTATION4!=4×3×2×1=24
READ IT ALOUD

Four factorial equals four times three times two times one.

In general, n! is the product of all positive integers up to n. By convention, 0!=1; this is the multiplicative identity and makes many counting formulas work cleanly.

NOTATION0!=1
READ IT ALOUD

Zero factorial equals one.

A larger value and a counting use

One more expansion is 5!=5×4×3×2×1=120.

Factorials also count the ways to arrange distinct objects when order matters. For three different books on a shelf, there are three choices for the first position, two for the next, and one for the last:

COUNT THE ORDERS3!=3×2×1=6
READ IT ALOUD

Three different books can be arranged in six orders.

If the books are named A, B, and C, the six orders are ABC, ACB, BAC, BCA, CAB, and CBA. This is a permutation: an arrangement where changing the order makes a different result. A combination counts a group when order does not matter.

Brief preview: factorials between whole numbers. The multiply-down definition here applies to nonnegative integers. A standard extension to positive non-integer inputs uses the Gamma function:
EXTENSIONx!=Γ(x+1),(12)!=Γ(32)=π2≈0.8862
READ IT ALOUD

One-half factorial is Gamma of three-halves, equal to the square root of pi divided by two, about zero point eight eight six two.

Why do the graph’s integer points match factorials? The Gamma function has Γ(1)=1,Γ(n+1)=nΓ(n). Repeatedly using this rule gives Γ(n+1)=n(n−1)⋯2·1·Γ(1)=n!, so for positive integers n the graph passes through (n,n!). It also passes through (0, 1) because 0!=Γ(1)=1. Between them, Gamma provides one standard smooth extension; the integer dots alone do not determine a unique curve, and this is not the original multiply-down rule. We will not derive the Gamma function here. Its calculus and special-function background is outside this handbook’s current scope. Python’s math.factorial accepts nonnegative integers, not fractional values.

Factorials count selections and support probability

Ordered selections: permutations

Suppose n distinct items are available and we fill r positions, with order mattering, where 0 ≤ r ≤ n. There are n choices for the first position, n − 1 for the second, and so on, ending at n − r + 1. The falling product is P(n,r)=n(n−1)⋯(n−r+1)=n!(n−r)!. The factorial quotient keeps the first r factors of n! by cancelling the remaining factors.

For three ordered places from five candidates, the choices are 5, then 4, then 3, so P(5,3)=5×4×3=5!(5−3)!=60. These are ordered selections; switching positions gives a different result.

Unordered selections: combinations

If order does not matter, each group of r items was counted r! times by the ordered formula—once for every ordering of the same group. Divide by r! to remove that repetition:

COMBINATION COUNTC(n,r)=(nr)=n!r!(n−r)!
READ IT ALOUD

Choose r from n: take the number of ordered selections and divide out the r! orderings of each group.

For a manager choosing a team of three from five candidates, n = 5 and r = 3. Substitute those values into the unordered-selection count:

C(5,3)=5!3!2!=1206×2=10

There are 10 different teams. The answer is a count of groups, not a probability. See the combinations lesson for more examples.

A probability example: five cards of one suit

Assume a uniformly shuffled standard 52-card deck and a five-card hand, where hand order does not matter. We count possible hands by choosing five of the 52 cards:

(525)=2598960

For a particular suit, choose five from its 13 cards. There are four suits, giving this many hands with all five cards in one suit:

4×(135)=4×1287=5148

The chance of five cards all sharing a suit, including straight flushes, is favorable hands divided by all hands:

51482598960≈0.001981=0.1981%

In standard poker-category names, a flush excludes a straight flush (five consecutive ranks of one suit). There are 10 possible consecutive runs per suit, so subtract 40 hands: 5,148 − 40 = 5,108. The probability of a flush in that narrower sense is:

51082598960≈0.1965%

This distinction corrects a common ambiguity in the phrase “flush probability.”

Why factorial growth matters

The counts climb quickly: 3!=6,5!=120,10!=3628800. A brute-force method that tries every ordering of n distinct items has n! candidate orders. This is one reason algorithms described as O(n!) can become impractical even for modest n. It describes a growth bound, not a guarantee that every problem checks exactly n! cases; see algorithm growth notation.

LESS EXPLICIT, THEN LIBRARY SHORTCUT

Keep the same calculation; hide some mechanics

A for loop handles the index update. For everyday Python, the standard library’s math.prod() can multiply an iterable’s values. We show both only after the explicit loop so the shortcut is not magic.

A little shorter · for loop 
n = 4
product = 1

for i in range(1, n + 1):
    product = product * i

print(product)

range stops before its end value, so n + 1 includes n.

Concise · standard library 
import math

n = 4
product = math.prod(range(1, n + 1))
print(product)

math.prod() does the repeated multiplication. It is a standard-library function, not a built-in like sum().
