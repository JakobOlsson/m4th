A QUICK GUIDE · MATHEMATICAL LETTERS

Letters are names. Context gives them a job.

Math uses familiar letters as compact labels for numbers, positions, functions, and other objects. Some letter choices are common conventions—but they are clues, not unbreakable rules.

Common patterns you may recognize

These patterns can help you get oriented. Always check how the author defines the symbols.

LettersOften used forExample role
x, y, zVariables or unknown valuesThe value we want to find or vary
a, b, cConstants, parameters, or coefficientsA value treated as fixed in a particular problem
i, j, kIndices or countersA position that changes as we move through a sequence
m, n, NSizes, counts, or boundsN can name a simulation's number of trials; context determines each letter's role.
f, gFunctionsA rule that takes an input and produces an output
u, v, wVectorsOften used as names for vectors; boldface or an arrow may distinguish them from scalar letters.
FnTerms in a named sequenceIn the Fibonacci example, F names the sequence and n selects a term.
No letters are off-limits.

An author can define x as a vector, use i as an ordinary index, or give a familiar letter a different role. The definitions and surrounding expression determine what a symbol means—not the letter by itself.

FUNCTION NOTATION

What does f(x) say?

NOTATION
y=f(x)=x+2 Substitute x = 3 y=f(3)=3+2=5
READ IT ALOUD

y equals f of x. The function adds 2 to its input. When x is 3, y is 5.

  • f is the name of the function (the rule).
  • x is the input given to the function.
  • y names the output, so y = f(x) says that y depends on x through the rule f.

In typeset math, variables and function names such as x and f are commonly italic. Names of standard operations such as sin and log are commonly upright. Typography can help, but definitions still matter.

In the Bézier-curve lesson, B(t) names a point on the curve, Pi is control point number i, n is the curve's degree, and Cj is the coefficient vector for the power tj. Those roles are defined for that formula, not universal meanings for the letters.

FAMILIAR LETTERS WITH SPECIAL USES

Conventions can overlap

Some letters have especially familiar meanings in particular topics:

  • i often labels an index; in complex numbers, i is the imaginary unit.
  • e often denotes the number used as the base of natural logarithms (about 2.718).
  • π often denotes the circle constant (about 3.142).
NOTATIONi2=−1
READ IT ALOUD

i squared equals negative one.

These uses do not make the letters forbidden for other purposes. If a paper uses the same symbol in different roles, its definitions and context should make the intended meaning clear.

SYMBOLS IN THE NEW WORKED EXAMPLES

Point coordinates and word-count lists

In the π estimation example, x and y are the two coordinates of one point in the unit square (each ranges from 0 to 1), the positive radius r is 1, N is a positive number of sampled points, and H counts those inside the quarter circle, so 0 ≤ H ≤ N. The hat over π in π^ marks a sample-based estimate, not the exact circle constant π.

In the word-count example, bold a,b name two equal-length count vectors built from the same ordered vocabulary; their entries are nonnegative integers. The bars ‖a‖ mean vector length. The label cosSim names the comparison function in that example; it is not a probability. As elsewhere, these roles come from the example, not from fixed meanings of the letters.

ALGORITHM GROWTH NOTATION

Big O, theta, and cases

In the counting-work lesson, Big O describes an upper bound on how an algorithm’s work grows. For a loop that makes n passes, O(n) is an upper bound. The symbol Θ(n) (“theta”) says the growth is tightly bounded by n from above and below.

In the halving comparison, n is a positive input size and the subscript 2 in log2n names the logarithm’s base, not a list position. If log2n=t, the real exponent t satisfies 2t=n. Counting whole halving rounds is a separate question when n is not a power of two; Big O describes growth rather than exact rounds.

Best case, worst case, and average case describe which inputs are being measured; they are not alternative Big O symbols. An average case is based on an assumed distribution of inputs, not just the most common input. When an exhaustive algorithm checks permutations of n distinct items, there can be O(n!) growth; this is an upper-bound description, not a claim that every input checks exactly n! cases. See the factorial-growth example and the counting-work lesson for more.

PROGRAM CORRECTNESS TERMS

Promises about a loop

A precondition is an assumption about the input before a program runs. A postcondition is the result promised when it finishes. A loop invariant is a statement true before every pass; proving it starts true and remains true is an induction-style argument. You also need to explain why the loop stops. The program-correctness lesson works through all three using the summation loop. Its k is just an index naming the terms in a sum, even though the Python loop calls its counter i.

In a proof by induction, k can instead stand for any one nonnegative integer. An induction hypothesis temporarily assumes a claim holds for that k, to show it also holds for k + 1. Together with a proven starting case, this proves the claim for all nonnegative integers. The job of k depends on its context.

COUNTING NOTATION

Choosing groups

A set is a collection of distinct items. The braces name the collection; symbols beside a set tell us whether an item belongs to it, or whether one set is contained in another.

Membership: is an item in the set?

Let S be the set containing 1, 2, and 3. The membership symbol in the example means “is a member of”; the crossed version means “is not a member of.”

MEMBERSHIPS={1,2,3},2∈S,4∉S
READ IT ALOUD

S is the set containing one, two, and three. Two is in S; four is not in S.

Describe a set by a condition

Instead of listing members, we can state a rule. Starting with the finite set S above, select the members greater than 1: that gives the set containing 2 and 3. The bar here means “such that,” not the “given that” bar in conditional probability.

SET-BUILDER NOTATION{x∈S|x>1}={2,3}
READ IT ALOUD

All numbers x in S such that x is greater than one form the set two, three. For each member of S, check the condition and keep it only if it passes.

Here x names one candidate member of S at a time; it can be 1, 2, or 3. A Python set comprehension can build this finite example: {x for x in {1, 2, 3} if x > 1} yields {2, 3}. Set operations such as .union() and .intersection() also act on finite Python sets, as in the examples below. In contrast, {x∈ℝ|x>0} means all positive real numbers; there are infinitely many, including non-integers, and a Python set cannot enumerate them all. See real numbers below.

Subsets: when one set fits inside another

A subset contains only members of another set. Here T contains 1 and 3, and both are members of S, so T is a subset of S. The inclusion symbol in this example means “is a subset of”; it allows the two sets to be equal.

SUBSETT={1,3}⊆S
READ IT ALOUD

T is the set containing one and three; T is a subset of S.

The bars around T in the example below mean the number of its members, called its cardinality. The vertical bars here mean “size of the set,” not absolute value.

SET SIZE|T|=2
READ IT ALOUD

The set T has two members.

Combining sets

For a second example, A={1,2},B={2,3}.

Union

Union, written with a cup-shaped symbol, collects every member that is in either set (including members in both).

NOTATIONA∪B={1,2,3}
READ IT ALOUD

The union of A and B is the set containing one, two, and three.

Intersection

Intersection, written with a cap-shaped symbol, contains only members shared by both sets.

NOTATIONA∩B={2}
READ IT ALOUD

The intersection of A and B is the set containing two.

On these same finite inputs, Python A = {1, 2} and B = {2, 3} give A.union(B) as {1, 2, 3}, and A.intersection(B) as {2}. Python's displayed set order is not guaranteed; set membership, not listing order, determines equality.

The empty set, written ∅, has no members.

From subsets to combinations

A combination is a subset of a chosen size; the order of its members does not matter. “Three choose two” counts the two-member subsets of a three-member set:

CHOOSE NOTATION(32)=3
READ IT ALOUD

There are three ways to choose a two-member subset from three items.

A coefficient is a number multiplying another quantity, as 3 does in 3x. A binomial has two terms joined by addition or subtraction, such as x+y. A binomial coefficient is the “choose” count used to count combinations. See the combinations lesson for the full list, derivation, and factorial formula.

SETS OF NUMBERS

Common number sets

The set symbols above also name familiar collections of numbers. Membership works the same way: for example, x∈ℝ says that the number x belongs to the real numbers.

ℕ Natural numbers

Here, 0, 1, 2, 3, and so on. Some authors start ℕ at 1 instead, so check the convention being used.

ℤ Integers

Negative and positive whole numbers, including zero: …, −2, −1, 0, 1, 2, …

ℚ Rational numbers

Numbers that can be written as a fraction of integers with a nonzero denominator, such as three quarters.

ℝ Real numbers

The numbers on the ordinary number line, including rational numbers and values such as π and 2.

ℂ Complex numbers

Numbers of the form a+bi, where a and b are real and i is the imaginary unit.

Vectors with real components: ℝd

Because the real numbers form a set, the notation in the heading names the set of ordered vectors with d real-number components. The superscript tells the number of components (the dimension); it is not an exponent applied to one vector. The membership symbol from above lets us state that a particular vector belongs to this set:

EXAMPLEu=(2,−1,4)∈ℝ3
READ IT ALOUD

The vector u with components two, negative one, and four belongs to three-dimensional real space.

So the real three-dimensional space is a set, and the example above says that u is one member of it. The vector lesson works with such component lists.

A PREVIEW · PROBABILITY NOTATION

Probability notation

NOTATIONP(X=k)
READ IT ALOUD

The probability that X equals k.

P(A) is commonly read as “the probability that event A happens.” An uppercase letter such as X often names a random variable—a value that depends on the outcome of a chance process. So P(X=k) means “the probability that X has the value k.” Another example uses Y for the net tokens in a hypothetical game: it can be +4 or −2. The letter alone does not fix a random variable’s meaning or possible values.

For conditional probability, A and B name events; the vertical bar in P(A|B) reads “given that B happened.” The events may overlap; the chance of B must be positive. In the ticket example, R is red and S is star, and Bayes’ rule relates the chance of red given star to the chance of star given red. The same bar in a set-builder description instead reads “such that.”

In the spread comparison, U and V are two random values, each with three equally likely outcomes; W stands for either or for another random value with a finite mean and variance. The Greek letter μ=E[W] names W’s mean, Var(W) names its variance, and σW names its standard deviation. Their roles are specific to this example, not fixed meanings for those letters everywhere.

This is a quick preview; see the probability lesson for a first worked example. In the summation lesson, this notation shows what probabilities are being added. The dice-probability example combines it with combinations.

LETTERS DO NOT TELL THE WHOLE TYPE

Scalar, vector, or matrix?

A letter alone does not tell us what kind of object it names. In these lessons:

  • A scalar is one number, such as a score of 5.
  • A vector is an ordered list of components, such as two coordinates of a point.
  • A matrix is a grid of numbers arranged in rows and columns.

Bold letters often name vectors, and capital letters often name matrices—but neither convention is a rule. Check each example’s definitions. See Common number sets for the numbers allowed as vector components.

Coordinates and displacement

A Euclidean coordinate system uses perpendicular axes (axes meeting at a right angle), such as x and y. With the same unit scale on both axes, the usual distance and angle rules apply.

A displacement vector records a change: subtract a starting point’s coordinates from the ending point’s coordinates. Its components describe that change even if you draw the arrow somewhere else. The vector and dot-product lesson works through matching components on these axes.

The double bars mean vector length

Let k be the vector with two real-number components, 3 and 4, measured on perpendicular axes with the same unit scale. Its norm (ordinary Euclidean length) comes from the Pythagorean rule: square each component, add, then take the square root.

VECTOR LENGTH
k=(3,4)
‖k‖=32+42=25=5
READ IT ALOUD

For the vector k with components three and four, its length is the square root of three squared plus four squared. That is five units on these equally scaled axes.

The two bars on each side, ‖k‖, enclose the whole vector; they are not two divisions or an instruction to multiply components. The zero vector has length zero, and length cannot be negative. Other definitions of vector norm exist; this example uses Euclidean length.

The bars depend on the object inside

These are common readings, not rules that hold in every subject. Use the objects already named here: the finite set S contains 1, 2, 3; vector k is (3, 4). For the scalar example, let real number x be −7. Capital M below stands for a real two-by-two matrix only in the last row.

Look inside the bars before choosing a meaning
Object insideNotationRead it aloud
Finite set S|S|=3“The size of S is three”: count its members. This is cardinality.
Real number x|−7|=7“The absolute value of negative seven is seven”: its distance from zero.
Vector k, single bars|k|=5“The length of k is five.” Some authors use single bars for a vector’s magnitude.
Vector k, double bars‖k‖=5“The norm of k is five,” using the Euclidean length calculated above.
Matrix M, double bars‖M‖“A norm of M”: a matrix-size measure, preview only. Its value depends on which norm is defined; this page does not compute one.

One bar does not always mean absolute value; two bars do not specify which norm. In other contexts, bars around a matrix may mean something else, too. Check the author’s definition before calculating. For another concrete vector norm, see word-count vectors. In the matrix-position example below, k is instead an index—its role changes with the example.

Matrix positions and dimensions

Read a matrix’s shape as rows by columns. In the matrix lesson, A and B are input matrices and C is their product. The first subscript chooses a row; the second chooses a column:

MATRIX ENTRYAr,k
READ IT ALOUD

The entry of A at row r and column k. The first position selects its row; the second selects its column.

The counts m, p, and n are positive whole numbers in this example:

  • A has m rows and p columns. B has p rows and n columns. The matching p counts allow multiplication.
  • r selects one of A’s rows, from 1 through m. k runs through the matching positions, from 1 through p.
  • Cr,c selects one output cell at row r, column c, with c from 1 through n.

These are roles in this product, not rules about the letters. In the project-scoring example, R names a ratings matrix, w a weight vector, and s the resulting score vector. An identity matrix is often called capital I (not the digit 1 or index i); its square size must fit the product.

Transpose: the superscript T

The superscript transpose symbol means swap rows and columns. If vectors are written as columns, u=[23] is a column and u⊤=[2,3] is a row. The mark tells us to perform that swap; it is not just a label for “this is a vector.”

Optional deep dive: keys, outer products, and normalization

This reference goes beyond identifying scalars, vectors, and matrices. Open it when you want to trace how those objects can work together in a vector-based lookup.

Key and value: roles in a lookup

A key helps look up a stored value. A person’s name could be a key and their phone number the associated value. A query is what we search with.

In this toy vector-based lookup, the key vector describes a pattern to match; the value vector holds what we want back. Compare the query with the key, then use the match score to retrieve a value. Key, value, and query are roles in this model—not special kinds of vectors.

Outer product: column times row

Multiplying a column vector by a row vector makes a matrix called an outer product. For a two-component value v=[57] and key k=[23], first transpose the key to make it a row:

k⊤=[2,3]

Now multiply each entry in the value column by the whole key row. The first value, 5, makes the first row; the second value, 7, makes the second row:

5×[2,3]=[5×2,5×3]=[10,15]
7×[2,3]=[7×2,7×3]=[14,21]

Put those rows together:

vk⊤=[10151421]

So the result has two rows (one per value component) and two columns (one per key component). Each entry is one value-component multiplied by one key-component. This is different from the dot product k⊤x, which is a single number. The lookup relation is:

TWO WAYS TO READ THE LOOKUP(vk⊤)x=v(k⊤x)
READ IT ALOUD

The matrix made from value v and key k, applied to query x, gives v scaled by the dot-product score of k and x.

Read the right-hand side first: compare query x with key k to get one dot-product score, then scale value v by that number. The matrix on the left does the same two steps. Adding outer-product matrices can store several such associations in a memory matrix; this is a toy model, not a promise of accurate retrieval.

The same rule works in any key dimension

The query x and key k must have the same number of components so their dot product is defined. For a new one-dimensional example, k=[2],x=[3],k⊤x=2×3=6. In a separate two-dimensional example, redefine key k with components 2, 1 and let query x have components 3, 4. Multiply at matching positions:

k⊤x=2×3+1×4=10

Let the key k and query x each have dk real components, where dk is a positive whole number. In short, k,x∈ℝdk. Index j selects matching components, starting at 1 and ending at dk:

MATCH KEY AND QUERYk⊤x=∑j=1dkkjxj
READ IT ALOUD

The dot product of key k and query x adds one product per matching component: k at position j times x at position j, for j from one through the key dimension.

The result is one number, a model-specific match score—not necessarily a probability or a measure of meaning. The value v can have a different positive whole-number component count dv: v∈ℝdv. Then the scaled output has dv components. If there are M stored key–value pairs, M counts the pairs, not the components in a vector.

Normalizing a vector to length 1

A vector’s length is also called its norm. In the usual Euclidean geometry, its length is found by extending the Pythagorean theorem to every component: square each component, add the squares, then take the square root. For k=[k1,…,kd]⊤, this is ‖k‖=k12+⋯+kd2.

Components can be negative: [−3,4]⊤ has length 5, because the components are squared. Normalizing a nonzero vector means dividing every component by its length; this keeps its direction (including any negative components) but makes its length 1. For example, k=[3,4]⊤,k^=[35,45]⊤.

If a key has been normalized, k⊤k=1. Therefore, when a query is exactly that key, the key’s match score is 1.

See the index in action

In the summation ∑i=1nai, i is the index, n is the upper bound, and ai is the term added at each step.
