PROBABILITY · EVENTS AND OUTCOMES

Probability asks how likely an event is.

Start with a fair six-sided die. Name the outcomes we care about, compare them with all possible outcomes, and then read the probability notation aloud.

Name the event before calculating its chance.

Suppose we roll one fair six-sided die once. Each face—1, 2, 3, 4, 5, or 6—is equally likely.

Outcome

One possible result of the roll, such as 4.

Event

A result, or collection of results, we care about. Let E be the event “the roll is even”: its outcomes are 2, 4, and 6.

NOTATION P(E)=36=12

E is the event of rolling an even number.

READ IT ALOUD

“The probability of event E is three out of six, which is one half.”

What the fraction means here

There are 3 favorable outcomes (2, 4, 6) out of 6 possible outcomes. Because the die is fair, all six outcomes have the same chance, so the probability is 36=12.

A probability is between 0 and 1

A probability of 0 means the event cannot happen; a probability of 1 means it is certain. Here, rolling a 7 has probability 0, and rolling one of the six faces has probability 1.

Probabilities are usually written on the 0-to-1 scale; multiply by 100 to express one as a percentage. For example, 0.5=50%, while 13≈0.333…≈33.3%. A probability can be any value in between, not just a whole percentage. Python floats approximate many such values; Fraction can keep rational values like 13 exact.

FROM AN EVENT TO PROBABILITY NOTATION

Use X to name the roll.

Let X be the number shown on the die. Then the event “roll a 4” can be written P(X=4). It has one favorable outcome out of six:

NOTATION P(X=4)=16
READ IT ALOUD

“The probability that X equals 4 is one out of six.”

X is a random variable: a name for the numerical result of a chance process. Here it can take the values 1 through 6.

CONNECT TO SUMMATION

An event with several outcomes adds their probabilities.

“At least 5” means that X is 5 or 6. The compact notation says to add the probability term for each index value:

NOTATION P(X≥5)=∑k=56P(X=k)
READ IT ALOUD

“The probability that X is at least 5 is the sum, as k goes from 5 through 6, of the probability that X equals k.”

Substitute each index into the whole term

The summand—the full expression being added—is P(X=k). The index k takes the values 5 and 6. Substitute each value for k in that entire expression:

When k = 5

P(X=k) becomes P(X=5).

For a fair die, this term is 1/6.

When k = 6

P(X=k) becomes P(X=6).

For a fair die, this term is 1/6.

EXPANDED, THEN EVALUATED ∑k=56P(X=k)=P(X=5)+P(X=6)=16+16=13
READ IT ALOUD

“The sum expands to the probability that X is 5 plus the probability that X is 6. That is one sixth plus one sixth, which is one third.”

This is the same bounds-and-term process as the summation lesson, but the whole term here is an expression involving a probability—not just the index itself.

Scope note: “favorable outcomes divided by all outcomes” works when the possible outcomes are finite and equally likely, as with a fair die. If outcomes do not have equal chances, add the probabilities of the outcomes in the event instead.

KEEP THE FRACTION EXACT

Use Python’s Fraction for a rational answer

Ordinary / produces a floating-point approximation. The standard-library fractions.Fraction represents this rational probability exactly and simplifies it from 2/6 to 1/3. Convert to float only when a decimal approximation is useful.

from fractions import Fraction

# P(X >= 5) = P(X = 5) + P(X = 6) = 2/6
p_x_at_least_5 = Fraction(2, 6)
print(p_x_at_least_5)        # 1/3
print(float(p_x_at_least_5)) # 0.3333333333333333

A rational number does not always have a finite decimal expansion: 13 repeats in decimal, but Fraction(1, 3) keeps it exact.

A PYTHON EXPERIMENT · MONTE CARLO

Simulate many rolls and compare.

A Monte Carlo simulation estimates a probability by repeating random trials. Here one trial is one die roll, and a “hit” is a roll of 5 or 6. Assume every roll is independent—the earlier rolls do not change the chances of later rolls—and the die stays fair. After many rolls, compare the observed fraction of hits with the exact probability 13.

ESTIMATE P^(X≥5)=hitsN
READ IT ALOUD

“The estimated probability that X is at least 5 is the number of hits divided by N, the number of rolls.”

We use random.Random(2026) so the example is repeatable in this Python runtime. This is a pseudorandom sequence with a fixed seed. In the code, N is the number of rolls, j numbers the trials, and x is the observed value of X on one trial; k names possible outcomes in the probability sum. randint(1, 6) can return either endpoint, 1 or 6.

One simulation · 1,000 rolls

Count hits, divide by the number of trials, and compare with the exact value.

import random
from fractions import Fraction

rng = random.Random(2026)
N = 1000  # sample size
hits = 0

for j in range(1, N + 1):  # trial index
    x = rng.randint(1, 6)  # observed X
    if x >= 5:  # event X >= 5
        hits = hits + 1

estimate = hits / N  # estimate of P(X >= 5)
exact_probability = Fraction(1, 3)  # exact P(X >= 5)
print("Trials (N):", N)
print("Hits:", hits)
print("Estimated P(X >= 5):", round(estimate, 4))
print("Exact P(X >= 5):", exact_probability)
Watch several sample sizes

Use the same seeded rolls and report the running estimate at 10, 100, 1,000, and 10,000 rolls.

import random
from fractions import Fraction

rng = random.Random(2026)
checkpoints = (10, 100, 1_000, 10_000)  # sample sizes N
hits = 0

for j in range(1, checkpoints[-1] + 1):  # trial index
    x = rng.randint(1, 6)  # observed X
    if x >= 5:  # event X >= 5
        hits = hits + 1
    if j in checkpoints:
        N = j  # current sample size
        estimate = hits / N  # estimate of P(X >= 5)
        print("Trials (N):", N,
              "hits:", hits,
              "estimate:", round(estimate, 4),
              "exact P(X >= 5):", Fraction(1, 3))

Simulation is evidence, not a proof. The exact argument is that 2 of the 6 equally likely faces are 5 or 6, so the probability is exactly 26=13. Under this model, each roll has that exact probability; in N independent rolls, the expected number of hits is N3, but the actual count varies. The law of large numbers says the observed fraction tends toward 13 as the number of rolls grows; it does not promise that each finite batch is exactly one third or that every checkpoint gets closer. This is sampling fluctuation, not a need to simulate the whole cosmos. A real die may also be slightly biased, which would be a difference between the model and reality. We can quantify typical fluctuations after learning more about averages and spread.

Small samples can look unrepresentative. In this seeded run, 10 rolls give an estimate of 0.6, far from 1/3. With only a few rolls, some faces may not appear, or a few may show up unusually often. There is no universal cutoff for a “large enough” sample: it depends on the accuracy you need and how rare the event is.

OPTIONAL PREVIEW · HOW MANY TRIALS?

Choose a sample size from the accuracy you want.

There is no universal minimum. For independent trials, a common rule estimates the margin of error for a 95% confidence interval (CI):

Here, m is the interval’s half-width. The “95%” describes the confidence level—not a 95% margin of error and not a 5% margin.

APPROXIMATE RULE m≈zp(1−p)N
READ IT ALOUD

“The margin is about z times the square root of the fraction with p times the quantity one minus p on top and N on the bottom.”

  • Lowercase p is the event probability used by the model (here, 13); P(A) denotes the probability of a named event A.
  • N is the number of independent trials.
  • z is a multiplier chosen for the confidence level; 1.96 is commonly used for an approximate 95% confidence interval.
  • m is the margin as a proportion: 0.01 means one percentage point.

For this die event, the approximate margin at the 95% confidence level is 0.0924 (9.24 percentage points) at 100 trials, 0.0292 (2.92 points) at 1,000, and 0.0092 (0.92 points) at 10,000. To plan for a chosen margin, rearrange the rule:

SOLVE FOR THE TRIAL COUNT N≈z2p(1−p)m2
READ IT ALOUD

“N is about z squared times p times the quantity one minus p, divided by m squared.”

For p = 1/3 and a target margin m = 0.01 (one percentage point), this gives about 8,537 trials.

This is an approximation, not a guaranteed error bound. The “95%” refers to long-run coverage: across repeated samples, intervals made this way would contain the true probability about 95% of the time; it is not a guarantee about one interval. The rule assumes independent trials and uses a normal approximation. If p is unknown, using p=0.5 is a conservative planning fallback because p(1−p) is largest there; it does not mean the event is actually 50% likely. Use a reasonable model estimate or pilot data when available. Very rare events and small samples need extra care.

Put the rule in a reusable Python function

The code uses the same symbols as the equations: p is the modeled event probability, uppercase N is the number of trials, z is the confidence multiplier, and m is the margin. The first helper computes m from p and N; the second computes the required N from p and a target m. math.ceil rounds that count up to a whole trial.

import math
from fractions import Fraction

def approximate_margin(p, N, z=1.96):
    m = z * math.sqrt(p * (1 - p) / N)
    return m


def trials_needed(p, m, z=1.96):
    N = math.ceil(z**2 * p * (1 - p) / m**2)
    return N

p = Fraction(1, 3)
for N in (100, 1_000, 10_000):
    m = approximate_margin(p, N)
    print("Trials (N):", N, "approximate 95% CI margin: ±",
          round(m * 100, 2), "percentage points")

m = 0.01  # target margin: one percentage point
N = trials_needed(p, m)
print("Trials for target m = 0.01:", N)

Fraction keeps the model probability 1/3 exact; the margin formula and its result are approximate, so Python converts to floating-point arithmetic when taking the square root.
